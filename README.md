If you are an osu! mapper, perhaps you've wondered: How can I put multiple songs into one mapset? Or maybe you know how, but you also know it's incredibly tedious.

This is the perfect tool for compilations. It lets you combine as many .osz files as you want into one mapset, where each difficulty will have its own title, audio, map and background.

How it works:
1. Export your maps as .osz files
2. Add them to the beatmap fuser
3. Choose the type of output (folder or .osz)
4. Input the mapset ID (not difficulty ID) for the pack (must be your mapset or it won't let you upload). Leave as -1 if you're creating a new mapset.
5. Input the name of the output file (unique name to prevent replaced files)
6. Create a placeholder (optional, read below)

*It is recommended to upload your mapset from a placeholder. The name and background you give it will show on the map's page and its background will be next to the title of each song in the mapset. You can't play it or map it without an audio file, but you can go to Song Setup and set the title, creator (you need to make that your name in order to upload), difficulty name, etc. as usual. You can also still drag and drop a background.

Go to https://github.com/NeroYuki/osu-map-compilation-script for turning maps into one marathon map (by NeroYuki)
